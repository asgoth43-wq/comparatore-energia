# Comparatore Energia & Gas

Un'applicazione web completa per il confronto delle tariffe luce e gas, completa di:
- **Auto-compilazione Bolletta via OCR** (con Tesseract.js)
- **Filtri avanzati per consumo e fasce orarie**
- **Scontrino dettagliato dell'energia** (secondo direttive ARERA)
- **Procedura guidata (Wizard Checkout)** a 3 passaggi per il cambio fornitore

## Come Pubblicare su GitHub Pages

1. Carica questi file all'interno del tuo repository GitHub.
2. Vai nelle **Settings** del repository.
3. Seleziona la voce **Pages** nel menu a sinistra.
4. Sotto **Build and deployment / Branch**, seleziona `main` (o `master`) e clicca su **Save**.
5. Il tuo sito sarà visibile online dopo pochi secondi!
